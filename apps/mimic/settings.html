The identifier Lutris uses for the game — usually everquest. This is the recommended way: launching through Lutris keeps the graphics settings that make the game start at all.
No Lutris? Launch through Wine directly
Both the folder and the prefix are required. Mimic will not guess a prefix — guessing wrong creates a second, empty EverQuest install instead of showing an error.
Only closes Mimic if the launcher was the thing that started it — a Mimic you already had open keeps running.
EverQuest ignores the frame limit in its own settings file — dgVoodoo.conf is the only place a cap works, and it ships unlimited. On a Deck that means the fan running flat out on character select and roughly half the battery life. 60 is a sensible cap (90 on an OLED). 0 means unlimited; blank leaves the file alone.
Read this before turning it on. EverQuest has no built-in auto-login, so Mimic types your password for you like a keyboard would. That means:
  • Your password is stored on this device in a file only your user account can read.
  • It only works in Desktop Mode. Gaming Mode does not allow it, and the launcher skips it there.
  • If anything steals focus while it is typing, the launcher stops rather than typing your password into another window.
Leave the password blank to keep the one already saved.

Old standalone Parser FOUND

This machine still has the older Parser.bat install, which starts itself every time you log into Windows. Mimic already includes the same parser, so only one of them uploads — whichever starts first. That is why Mimic can show “Read-only mode: parser is the active uploader.” Nothing is double-counted, but the older one wins the race every login, so Mimic's newer parser never gets to do the work.

Retiring it stops the old parser and removes its auto-start and shortcuts. Nothing in your EverQuest folder is deleted — running Parser.bat again brings it all back if you ever want it.

Windows Defender

Real-time scanning inspects every file open, and both halves of this are file-heavy: EverQuest's logs are append-only and grow into the gigabytes, and Mimic re-reads its spell/item catalogs on each start. Excluding those two folders is the biggest single speed-up available on Windows.

This is opt-in and never silent. You will see the exact folders below, and Windows will ask for permission once. Nothing else is touched — Defender keeps protecting the rest of your machine.

Windows clock

Every parse timestamp comes from this machine's clock, so a clock that drifts puts your deaths, casts and kills at times nobody else saw — and the raid's merged numbers get it wrong for everyone, not just you.

This does not just set the time once. We have watched that drift back within two days. It sets the Windows Time service to start automatically, starts it, and resyncs — fixing the reason the drift returns. Windows will ask for permission once.
