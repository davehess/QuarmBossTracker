### 459. [mimic-overlays] Minimized overlays keep moving and resizing; the resize rule while folded (2026-10-28)
The guild lead: *"minimized overlays need to be draggable and resizable still"*. The session's rule, on Mimic beta `bc260ee9`:
- A **folded** overlay (title row only) moves freely and resizes in width; its height stays the row and is never saved as a
  floor, so unfolding gives back the saved full height (a width change made while folded carries over).
- A **designed mini** resizes both ways and keeps its own height floor (`<key>MiniFloor`), so it no longer takes or overwrites
  the full-size floor (a mini can now shrink to its content).
- A **collapsed Canvas strip** moves by its ✥ and resizes in width only.
Open: layout profiles do not save the mini floor; the HUD ring has no resize grip; folding the alerts window (grow-up) restores
top-anchored on unfold.
